# Редактор Ирины — подготовка

Подготовлен Pages CMS: `.pages.yml`, отдельные редактируемые JSON-файлы и сборка из этих файлов. Это интеграция настоящего редактора с GitHub, а не браузерная демо-админка. Онлайн-вход и публикация ещё не подключены и не проверены.

## Возможности

- Визуальные текстовые блоки и заголовки страниц, FAQ, фотографии и alt-тексты.
- Список работ: добавить название, описание, отображаемую цену и несколько фотографий; скрыть работу; менять порядок внутри группы галереи.
- Старые работы оставлены без выдуманных названий, описаний и цен.
- Сетка оригинала отделена от редактируемого содержимого.
- Новые фотографии сохраняются в `public/assets`, тексты — в `content/editor`, история — в GitHub.

## Что нужно подключить

1. Разрешить GitHub App Pages CMS чтение и запись только репозитория AndrewFreeman136/fallen-tree-vancouver. Требуется явное подтверждение владельца перед выдачей доступа. Репозиторий остаётся приватным, но сторонний сервис сможет читать его код и изменять файлы.
2. Загрузить подготовленные изменения в отдельную ветку `editor-drafts`; проверить интерфейс на реальном аккаунте. Не менять production main на этапе проверки.
3. Проверить Cloudflare preview deployment ветки; Ирина редактирует эту ветку, смотрит фактический предпросмотр, затем изменения публикуются слиянием в main. Однокнопочная публикация из CMS пока не реализована.
4. Подключить отдельный вход Ирины. Не отправлять приглашение без поручения владельца. Подтвердить её адрес и объём прав на выбранном экране.
5. Пройти полный тест: вход → фото/текст → сохранение → другое устройство → предпросмотр → слияние → сайт → откат. До этого этап 2 не объявлять завершённым.

## Проверки

`node build.mjs && node check.mjs` проверяет ресурсные ссылки и страницы. `node test-editor.mjs` проверяет изменение текста, добавление/скрытие/перестановку работ и новые фото; опасные HTML и пути файлов отклоняются. Нулевые изменения редактора дают идентичные HTML/CSS относительно staging-копии.

Перестановка между тремя исходными группами галереи пока не поддерживается. При публикации длинных текстов нужно проверять мобильную раскладку. При замене форматированного блока визуальный rich-text редактор может изменить исходные inline-стили: необходим реальный визуальный тест. Не удаляйте используемые фотографии из библиотеки: сборка остановится при отсутствующем файле.

## Стоимость и ограничения

На 11 октября 2026 официальный сайт Pages CMS называет онлайн-версию бесплатной: https://pagescms.org/. Это не гарантия неизменных условий. Действуют также лимиты GitHub и Cloudflare. Платные подписки и автоматическое платное расширение не включены. При превышении лимитов публикация может задержаться или остановиться.

## Откат

Откатить соответствующий коммит содержимого в GitHub и дождаться сборки Cloudflare. Исходные `content/pages.json` и `content/assets.json` не перезаписаны. `prepare-editor.py` предназначен только для первичного переноса: повторный запуск перезапишет редакторские файлы, поэтому после подключения CMS его не запускайте.
