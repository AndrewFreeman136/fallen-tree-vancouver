# Редактор Fallen Tree Vancouver

Сайт: https://www.fallentreevancouver.com/

Редактор: https://app.pagescms.org/andrewfreeman136/fallen-tree-vancouver/main/file/works

Вход через текущий GitHub AndrewFreeman136.

1. Убедитесь, что сверху выбрана ветка **main**. Она публикует изменения на основном сайте.
2. Выберите страницу слева. Works позволяет менять фотографии, названия, описания, отображаемые цены, порядок внутри группы и видимость работ. Остальные разделы содержат тексты страниц и FAQ.
3. Для новых фото используйте Media. Не удаляйте фотографии, которые используются на страницах.
4. Нажмите **Save**. Cloudflare соберёт и опубликует сайт автоматически. После завершения сборки обновите страницу сайта и проверьте результат, особенно на телефоне.

Для проверки изменений до публикации переключитесь на **editor-drafts**. Её сохранения обновляют https://editor-drafts.fallen-tree-vancouver.pages.dev/. Для переноса черновика на основной сайт потребуется слияние изменений в main через GitHub.

Формы Contact и Reserve Preservation отправляются через FormSubmit на fallentreevancouver@gmail.com. При первичной настройке владелец должен подтвердить адрес из письма активации. Сохранена защита reCAPTCHA и прямая ссылка email на случай сбоя. Сайт не подтверждает бронь и не принимает оплату. Отображаемая цена работы не включает корзину или оформление заказа.

История изменений хранится в GitHub. Для отката верните нужное изменение коммитом; Cloudflare опубликует восстановленную версию. Не запускайте prepare-editor.py повторно: он предназначен для первого переноса содержимого.

Не меняйте Configuration и настройки доступа для обычного редактирования сайта.
