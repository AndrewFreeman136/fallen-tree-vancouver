# Fallen Tree Vancouver — независимая статическая копия

Снимок публичного сайта от 10 октября 2026 года. Тестовая версия для приёмки, а не завершённый перенос домена. Сайт на английском; документация на русском.

## Запуск и сборка

Нужен Node.js 18 или новее. Внешние npm-пакеты не требуются.

```sh
node build.mjs
node check.mjs
node server.mjs
```

Локальный адрес: `http://127.0.0.1:4173`. Остановка сервера: Ctrl+C. Сборка по умолчанию использует закрытый адрес Sites и `noindex,nofollow`; `dist/` содержит готовый сайт.

Для финального размещения на домене после приёмки и подготовки DNS:

```sh
node build.mjs --production
node check.mjs --production
```

В Cloudflare Pages: Framework preset — None; build command — `node build.mjs --production`; output directory — `dist`; root — корень этого проекта. Для приватной тестовой копии команда `node build.mjs`. Вариант `--production` разрешает индексацию и устанавливает основной адрес `https://www.fallentreevancouver.com`. Не включать его для несогласованного публичного тестового дубля.

## Файлы и редактирование

- `content/pages.json` — исходные заголовки, SEO-описания, тексты HTML, порядок секций/галерей, ссылки, вопросы FAQ и параметры сетки. Есть `/` и сохранённый псевдоним `/home`.
- `content/assets.json` — исходный URL → локальная фотография, размеры, объёмы, лицензии шрифтов. При добавлении фотографии необходимо добавить локальный файл и соответствие в этот файл либо расширить сборщик.
- `public/assets/` — локальные WebP/PNG и шрифты Sansita/Nunito Sans с лицензиями SIL OFL 1.1. Действующая подписка Squarespace для их загрузки не требуется.
- `public/styles.css`, `public/site.js` — собственные стили и взаимодействия: меню, клавиатура, подготовка email. FAQ использует HTML `details`.
- `build.mjs` — генератор HTML/метаданных, sitemap, robots, CSS сетки и 404.
- `check.mjs`, `verification.json` — проверка полноты текстов, ссылок, локальности ресурсов, количества FAQ и фотографий.
- `.openai/hosting.json` — идентификатор тестового сайта Sites. Для Cloudflare это не зависимость.
- `MIGRATION.md` — порядок переноса, DNS, откат, лимиты и план редактора.
- `AUDIT.md` — инвентаризация, проверки, отличия и оставшиеся ограничения.

Изменяйте редактируемые данные в `content/`, затем пересобирайте сайт. Изменения непосредственно в `dist/` будут перезаписаны. Административный редактор пока не реализован. Историю правок хранить в Git; перед редактурой фотографий сохранять оригиналы вне публикуемой папки.

## Контактные обращения

Обе формы сейчас только подготавливают черновик в почтовом приложении посетителя через `mailto:`. Кнопка называется **Open email draft**. Сайт сам не отправляет письмо, не резервирует дату и не объявляет отправку успешной. Есть прямая ссылка на `fallentreevancouver@gmail.com`. Нужна настроенная почтовая программа; если она не открывается, адрес можно скопировать.

Серверный обработчик и доставка не подключены и не проверены. До возврата обычной кнопки Send/Reserve my spot необходимо выбрать сервис с учётом бесплатной квоты, подтвердить адрес владельцем, защитить endpoint от спама и выполнить согласованный тест доставки. Секреты нельзя включать в статический HTML или Git.

## Публикация и владение

Текущая версия Sites закрыта для владельца. Исходники переносимы на Cloudflare Pages и другие статические хостинги. Репозиторий и аккаунт окончательного хостинга должны контролироваться Ириной/заказчиком; передача в отдельный аккаунт Ирины ещё не выполнялась.

Не выключать Squarespace, пока домен, HTTPS, обращения и резервные копии не проверены после переключения. Оплата и корзина отсутствуют по заданию; история старых заказов в публичную копию не входит.
